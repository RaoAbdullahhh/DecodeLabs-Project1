🤖 Rule-Based AI Chatbot | Python Project

Developed a conversational AI chatbot using Python and rule-based logic. 
This project focuses on core programming concepts such as control flow, 
decision-making, loops, and user interaction.

The chatbot can:
• Respond to greetings and questions
• Display current time and date
• Handle unknown inputs intelligently
• Provide jokes and motivational messages
• Run continuously until the user exits

Through this project, I strengthened my understanding of Python fundamentals, 
logical thinking, and chatbot architecture while improving user experience 
through human-like conversational responses.

Tech Used:
• Python
• If-Else Logic
• Loops
• Time Module

This project marks an important step in my journey toward Artificial Intelligence 
and software development.
